# Runtime dependency review

Date: 2026-10-17. Result: **release blocked pending dependency updates and applicability review**.

The packaged backend was checked against the [OSV batch API](https://google.github.io/osv.dev/post-v1-querybatch/) using 141 unique Maven coordinates. Coordinates came from packaged JAR metadata, matching local Maven artifact paths, and the official Maven Central POM for Boot jarmode tools. No application data or credentials were submitted. All packaged runtime JAR names were mapped; this inventory is not a signed SBOM.

OSV returned 20 flagged packages and 77 distinct advisory IDs: 10 critical, 29 high, 30 moderate, and 8 low according to advisory database severity. These are **version matches**, not proof that every vulnerable feature is reachable. Preconditions and mitigations need explicit review. For example, this app supplies its own Spring Security filter chain, uses JWT rather than Tomcat DIGEST/FORM authentication, and does not configure XSLT/SSE views. Those observations must not be used to dismiss unrelated findings or replace a patched dependency baseline.

The frontend lockfile was updated within existing version ranges; fresh installation, type/build checks and `npm audit` report **zero findings**. Backend dependencies were inventoried rather than broadly upgraded during deployment preparation. Container OS packages, build-only Java dependencies, exploitability, and provider images have not received a complete independent scan.

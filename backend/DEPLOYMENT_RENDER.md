# Render Deployment

This project deploys to Render as a Docker web service. Render's native runtimes do not include Java, so the Dockerfile builds the Spring Boot jar with Maven and runs it on Eclipse Temurin JRE 17.

## Files

- `backend/Dockerfile`: multi-stage Maven build and slim runtime image.
- `backend/.dockerignore`: keeps local build output, Git metadata, IDE files, and `.env` secrets out of the Docker build context.
- `render.yaml`: Render Blueprint for the API web service. It remains at the repository root and points Render at the `backend/` Docker context.
- `backend/src/main/resources/application-prod.yaml`: production profile overrides.

## Required Render Environment Variables

Set these in Render when the Blueprint prompts for values:

| Key | Value |
| --- | --- |
| `DB_URL` | `jdbc:postgresql://<neon-host>/<database>?sslmode=require&channelBinding=require` |
| `DB_USERNAME` | Neon database user |
| `DB_PASSWORD` | Neon database password |
| `CORS_ALLOWED_ORIGINS` | Comma-separated frontend origins, for example `https://your-frontend.onrender.com` |

The Blueprint also sets or generates:

| Key | Value |
| --- | --- |
| `PORT` | `10000` |
| `SPRING_PROFILES_ACTIVE` | `prod` |
| `JWT_SECRET` | generated by Render |
| `JWT_EXPIRATION_MS` | `86400000` |
| `HIBERNATE_DDL_AUTO` | `update` |
| `SQL_INIT_MODE` | `always` |

## Deploy Steps

1. Push the repository to GitHub/GitLab.
2. In Render, create a new Blueprint from the repository.
3. Enter the prompted secret values for `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, and `CORS_ALLOWED_ORIGINS`.
4. Deploy.
5. Confirm the health check passes at `/actuator/health`.

## Production Notes

- Keep `.env` local only. Do not commit database credentials.
- `data.sql` seeds one admin account: `admin@healthmate.com` with initial password `admin123`. Change this password after first login.
- `HIBERNATE_DDL_AUTO=update` matches the current project because it has no migration tool. For stricter production control, add Flyway or Liquibase and change this to `validate`.
- Rotate any database password that was shared outside Render's secret manager.
